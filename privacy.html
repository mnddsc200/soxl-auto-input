SOXL Auto Input — Privacy Policy / 개인정보처리방침

Last updated: 2026-11-20

SOXL Auto Input is a personal Google Apps Script tool used only by its owner. It is not offered to other users.

Data accessed / 사용하는 데이터

  • Google Sheets: reads and updates the owner's own spreadsheet. / 본인 구글 시트 읽기·쓰기
  • Email: sends notifications only to the owner's own address. / 본인에게 알림 메일 발송
  • Scheduled execution and external requests: runs on a schedule and sends result notifications to the owner. / 예약 실행 및 본인 알림 발송

Data use and sharing / 데이터 이용·공유

Data is used only to perform the functions above for the owner. The app does not sell, share, or transfer Google user data to third parties, and does not store it outside the owner's own Google account.

데이터는 위 기능을 수행하는 데에만 사용하며, 구글 사용자 데이터를 제3자에게 판매·공유·전송하지 않고 소유자 본인의 구글 계정 밖에 저장하지 않습니다.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access / 권한 해제

Access can be removed at any time at myaccount.google.com/permissions.
